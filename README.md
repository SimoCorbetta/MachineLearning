# MachineLearning
The aim of the project was to perform regression, classification and clustering on Online Shoppers Purchasing Intention dataset using traditional python machine learning libraries such as sklearn. 
The Online Shoppers Purchasing Intention dataset is a publicly available dataset  that contains information on the browsing behavior and purchase history of online shoppers. The dataset contains different sessions, and it was formed so that each session would belong to a different user in a 1-year period to avoid any tendency to 
a specific campaign, special day, user profile, or period. The dataset has been made available on the UCI Machine Learning Repository.
